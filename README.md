## About the Project

Comp Calc is a compact workflow utility for visual artists, delivered as a web page built with HTML. It can be opened in a compatible browser, so using it does not require a conventional desktop installation.

The tool is designed to sit alongside an artist's existing creative workflow. Because it uses a lightweight web format, it is convenient for quick calculations and references during preparation, production, and related tasks.
